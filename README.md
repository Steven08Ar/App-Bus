# App Bus

Aplicación **web y móvil** para seguir en tiempo real la ubicación de un **bus universitario** (paradas, recorrido y
llegada estimada) en el área metropolitana de Bucaramanga.

- **Mapa propio**, sin depender de Google Maps ni de otros proveedores de pago.
- **Diseño nativo para cada plataforma**: la app de Android se diseña como una app de Android y la de iOS como una de iOS.
- **Un solo backend** compartido por Android, iOS y la web.

> **Estado: idea.** Todavía no hay código ni arquitectura decidida.
